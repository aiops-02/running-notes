group of labels
================

group-1: labels that builds the request
Discovered labels: service discover gave these labels

target URL: http://<exporter-ip>:<port-no>/metrics

__scheme__ -> http/https -> default is http
__address__ -> IP:port   -> targets will set the address in YAML
__metrics_path__ -> /metrics -> metrics_path in YAML
__scrape_interval__ -> 15sec by default -> global config in YAML
__scrape_timeout__ -> "10s" by default -> global config in YAML
__param_name__key -> value

labels that helps prometheus to builds the requests
http://10.0.2.200:9101/metrics?key=value

white box monitoring vs black box monitoring
============================================
white box -> knowing the system internals, we run exporters along with targets. we scrape metrics and analyse

black box -> we dont know system internals. actually we dont care. we dont have any details. is the application running or not?

we can check SSL certificate is valid or not? is going to expire or not?
we can check http -> https or not?
application is responding or not
DNS query is resolving or not

everything is module inside black box monitoring
prober -> http/https, DNS, TCP, ICMP(ping)

each module does one work
http_2xx: -> getting response from a website within 5 sec or not

https_2xx: this will check if the certificate is valid or not, expiry or not, certificate exists or not

http_redirects_to_https -> http to https redirecting or not
