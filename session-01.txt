Metrics -> What is wrong?

Push vs Pull
============
Push -> When there is event we get notification or data
Pull -> We continously get data periodically every 15sec.

Observability needs pull model when there is need for complete data for analysing the trend

When push model is valid?
=========================
if there is a job that runs only for short time say 5sec. -> application send the data to push gateway when job is completed

when networking rules are strict.

server -> app. app should allow monitoring server to connect on particular port.
app -> server. outbound/ingress. 

Metrics collection Prometheus

agent model
===========
Targets -> Servers/applications from which we need data/metrics. We have various kinds of platforms and applications

It is impossible for prometheus to contact targets directly and get the data in prometheus format

exporters -> are like agents that runs along side of target. prometheus contacts exporters then exporters read the information from targets and updates to prometheus

every 15sec
=============
prometheus -> agent/exporters -> read the data from targets -> convert into prometheus format -> send it to prometheus
